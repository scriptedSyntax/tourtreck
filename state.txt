# CURRENT SYSTEM STATE

Last updated: July 2026

## Overview

The project is an integrated, reusable single-shop ecommerce system.

One deployment represents one shop. It is not multi-tenant and does not include staff or manager roles.

Technology:
- Backend: Django 6, Django REST Framework, Simple JWT
- Frontend: Next.js 16, React 19, Tailwind CSS 4
- Local database: SQLite
- Authentication transport: Next.js same-origin server routes with HttpOnly JWT cookies

Roles:
- SUPER_ADMIN
- ADMIN
- CUSTOMER

## Accounts and access

Complete:
- Custom email-based Django user model
- Customer registration and login
- JWT access and refresh tokens
- Logout and token blacklisting
- One active API login per user through API-session version rotation
- Customer profile endpoint and minimal account dashboard
- Customer order history
- Customer order confirmation email after checkout
- New-order notification to the configured shop email
- Customer email when an order status changes
- SUPER_ADMIN manages all users
- ADMIN sees and manages CUSTOMER users only
- CUSTOMER cannot access Django Admin
- Authentication responses are non-cacheable
- Unauthenticated account navigation remains hidden

## Shop and branding

Complete:
- Dynamic business name, logo, favicon and colors
- Default SEO title and description
- Shop phone, WhatsApp, email, location and currency
- Delivery fee and pickup option
- Homepage sections with a super-admin-controlled section limit
- Promotional ad heroes with image and safe destination link
- Newsletter subscriptions visible in Django Admin
- Categories and products
- Up to five inline images per product
- Permanently embedded branding on uploaded product images
- Product ratings and verified-purchase reviews
- Upload size, dimensions, content verification and re-encoding

SUPER_ADMIN controls hidden SiteSetting branding. ADMIN manages ordinary shop operations but cannot see or manage SiteSetting.

## Orders and carts

Complete:
- Guest local frontend cart
- Authenticated backend cart foundation
- Cart and cart-item APIs
- Guest and customer checkout
- Pickup and delivery
- Delivery-location validation
- Server-controlled product prices
- Order and order-item snapshots
- Order statuses: PENDING, PROCESSING, EN_ROUTE, DELIVERED, CANCELLED
- Django Admin inline items and order status actions
- Customer order history

Stock availability is validated during cart and checkout. No additional stock workflow is planned in the current scope.

## Payments

Complete:
- Payment methods
- Multiple transactions per order
- PENDING, PAID, FAILED and REFUNDED statuses
- Paid amount, balance and payment status calculations
- Payment admin action to mark transactions paid
- Cash/manual processor foundation
- Bank, M-Pesa and card processor placeholders

Not yet implemented:
- Real M-Pesa gateway calls
- Real card gateway calls
- Automated bank reconciliation

- Dynamic admin branding, defaulting to “Admin”

- Search, relevant filters and ordering

- Sales summary based on the filtered order list
- Total paid and outstanding balances

## APIs

Complete endpoint groups:
- Public shop settings and profile
- Homepage sections and ad heroes
- Categories and products
- Product details and reviews
- Newsletter subscription
- Login, refresh, logout, registration and current user
- Customer order history/detail
- Cart creation, retrieval and item management
- Checkout
- Admin category/product/order/payment management
- Admin sales summary

Public shop reads allow anonymous access. Customer endpoints require CUSTOMER authentication. Admin APIs require ADMIN or SUPER_ADMIN. Branding writes require SUPER_ADMIN.

## Security state

Complete:
- Secure HttpOnly host-only authentication cookies
- Production __Host- cookie names
- Single-session token-version enforcement
- Centralized frontend authentication state
- Exact Origin checks and double-submit CSRF protection for sensitive mutations
- JSON content-type and body-size enforcement
- Safe public error contract with request IDs
- Raw backend responses and technical errors hidden from visitors
- Database-backed operation/account/cart throttling
- Production configuration system checks
- Environment-controlled CORS and CSRF origins
- CSP, HSTS support, frame denial, nosniff, referrer and permissions headers
- Production browser source maps disabled
- Private-IP image optimization remains disabled
- Restricted production image origins
- Safe promotional link validation
- Verified delivered-purchase review requirement
- Persistent application_cache table created locally

## Local run commands

Backend:
cd backend
.\.venv\Scripts\Activate.ps1
python manage.py migrate
python manage.py createcachetable
python manage.py runserver

Frontend, in another terminal:
cd frontend
npm ci
npm run dev

URLs:
- Storefront: http://localhost:3000
- Backend: http://127.0.0.1:8000
- Django Admin: http://127.0.0.1:8000/admin/
